# Definition of Done (DoD) — HA Irrigation Engine

A Sprint or Feature is considered **DONE** if and only if all of the following criteria are satisfied:

1. **Working Implementation**:
   - All code is production-ready, fully typed (Python 3.12+), and error-handled.
   - Zero placeholders, zero TODOs, zero temporary mockups.

2. **Test Suite**:
   - 100% test pass rate.
   - Unit tests covering all domain models, adapters, engine logic, and generators.

3. **Documentation**:
   - `.ai/` documentation suite fully updated to match any architecture or code change.
   - `README.md`, `CHANGELOG.md`, `PROJECT_STATUS.md`, `ROADMAP.md`, `DECISIONS.md` updated.
   - Sprint report `docs/sprint-XX.md` created with deliverables and release notes.

4. **Architecture & ADRs**:
   - Architectural decisions documented as ADRs under `docs/adr/`.

5. **Release & Git**:
   - Clean git commit history using Conventional Commits convention.
