# HA Irrigation Engine

## Objetivo

Desarrollar un framework Open Source para Home Assistant que permita controlar sistemas de riego de forma profesional.

No es una automatización.

No es un dashboard.

Es una plataforma modular.

Debe poder soportar cualquier fabricante mediante adaptadores.

El primer dispositivo soportado será:

- Sonoff SWV-BSP
- Zigbee2MQTT
- Home Assistant

Debe diseñarse pensando desde el primer día en soportar otros fabricantes.

---

## Filosofía

El usuario solo debe configurar el dispositivo.

Todo lo demás debe descubrirse automáticamente.

Debe ser sencillo de instalar.

Debe ser sencillo de mantener.

Debe ser sencillo de ampliar.

Debe parecer una integración oficial de Home Assistant.

---

## Objetivos

- Modular
- Escalable
- Fácil de usar
- Dashboard profesional
- Reutilizable
- Open Source
- Calidad de producción

---

## No objetivos

No depender de Sonoff.

No depender de Zigbee.

No depender de MQTT.

No contener lógica en el dashboard.
